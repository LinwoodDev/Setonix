Open **Settings** on the home screen or from the game menu. Settings apply to your app installation; they do not change the shared world's rules.

## General

View the current version, check for **Stable** or **Nightly** updates, reopen the introduction, and access documentation, release notes, source code, licenses, and privacy information. Checking for updates contacts the Setonix website. Nightly builds contain newer development changes; see [versions](/community/versions/) before moving important games between releases.

## Personalization

| Option | Purpose |
| --- | --- |
| Theme | Follow the system, or choose light or dark mode |
| Design | Choose an available app color design |
| Locale | Follow the system language or choose a supported language |
| Density | Choose desktop, compact, standard, or comfortable spacing |
| High contrast | Increase contrast in the interface |
| Native window title bar | Use the platform title bar where available |
| Stacked cards | Change how cards are displayed in the hand view |

Some controls depend on your platform. Pack item names also depend on the [translations included by the pack](/docs/v1/packs/translations/).

## Inputs

Adjust **Scroll** sensitivity to change camera scrolling. Use the game menu's **Zoom** control or touch gestures for zooming. See the [controls reference](/docs/v1/playing/#move-around) for keyboard shortcuts.

## Data

On native platforms, **Data directory** chooses the saved-world storage location; **Default path** restores the default selection. **Export** packages saved worlds into a ZIP archive. Export a backup before moving storage.

These filesystem controls are unavailable on the web. Browser games use local storage; export individual games to keep a separate backup. Account keys have their own [encrypted backup workflow](/docs/v1/accounts/).

## Server lists

Enable or disable **Load default server list** and add, remove, or reset custom sources. These sources populate the multiplayer browser. Loading a list contacts its provider; adding a server manually is available independently.
