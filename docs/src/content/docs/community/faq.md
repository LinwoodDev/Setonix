## Do I need an account or internet connection?

Local games do not need an account or an internet connection once the app and content are available on your device. Accounts are local identities for servers that require authentication. LAN multiplayer can work without an internet connection when all required content is installed; public directory and Swamp services need network access.

## Does Setonix enforce game rules?

Custom games are sandboxes. Chess supplies a board and pieces, with players enforcing the rules. Blackjack includes scripted dealing, turns, and scoring. Packs can add more scripted modes. See [games and templates](/docs/v1/worlds/).

## Can I play in a browser?

Yes. Open the [web app](https://web.setonix.world) or install it through your browser's install action where supported. Luau game modes also run in the browser. Browser saves stay in that profile's local storage, so export important games before clearing site data.

The browser can join multiplayer games; starting a hosted session from the app is available on native platforms. See [multiplayer](/docs/v1/multiplayer/).

## Can I move games and accounts between devices?

Export games as `.stnx` files, then import them on the other device. Back up account keys separately with a passphrase and import that backup to preserve your server identity. See [accounts and backups](/docs/v1/accounts/).

## Which platforms are available?

See [Downloads](/downloads/) for Windows, Linux, Android, macOS, the iOS preview, and the web app, including each platform's installation instructions.

Check the [troubleshooting guide](/docs/v1/troubleshooting/) for protocol mismatches, missing pack identifiers, authentication, connection settings, and browser issues. If you still need help, contact the [community](/community/).
